1. Información General

Nombre del sistema: Calculadora de Nota Mínima

Tipo: Aplicación web estática (HTML, CSS y JavaScript)

Propósito: Calcular la nota mínima que el estudiante debe obtener en el tercer corte para alcanzar una nota final mínima de 3.0.

Archivos principales

  • Examen/Interfas.html: Interfaz del usuario.
  • Examen/proceso.js: Lógica de cálculo y validaciones.
  • Examen/Estilo.css: Estilos visuales.

2. Alcance

El sistema permite ingresar notas, calcular la nota mínima y mostrar mensajes de resultado según el desempeño. También permite limpiar los campos y navegar entre pantallas.

  • Calcular nota mínima necesaria para aprobar.
  • Mostrar resultados: “Ya pasaste”, “Imposible”, o “Necesitas al menos X”.
  • No incluye persistencia de datos ni roles de usuario.

3. Actores

ActorDescripción
Estudiante / UsuarioPersona que introduce las notas y consulta su nota mínima.
Sistema (Aplicación Web)Ejecuta cálculos, valida y muestra los resultados.

4. Reglas de Negocio y Fórmula Principal

Pesos: C1 = 0.33, C2 = 0.33, C3 = 0.34

Nota mínima deseada: 3.0

Fórmula: (3.0 - ((nota1 * 0.33) + (nota2 * 0.33))) / 0.34

Casos Especiales

  • notaMinima > 5 → “Imposible”.
  • notaMinima ≤ 0 → “Ya pasaste”.
  • 0 < notaMinima ≤ 5 → “Necesitas al menos X”.

5. Requisitos Funcionales y No Funcionales

Requisitos Funcionales

  • RF-001: Ingreso de notas sin recargar la página.
  • RF-002: Cálculo de nota mínima según fórmula.
  • RF-003: Mostrar resultado con estilo dinámico.
  • RF-004: Botón para limpiar formulario.
  • RF-005: Pantalla de inicio y transición fluida.

Requisitos No Funcionales

  • Rendimiento rápido (<100 ms).
  • Compatibilidad con navegadores modernos.
  • Validación de datos numéricos y rango (0 a 5).
  • Mensajes legibles y usabilidad clara.
  • Seguridad básica (sin conexión externa ni almacenamiento).

6. Interfaces e Identificadores

  • form#notas: Contiene los campos de ingreso.
  • div#resultado: Muestra el resultado.
  • #limpiar: Limpia formulario y resultado.
  • #iniciar-calculadora: Muestra calculadora y oculta inicio.

7. Casos de Prueba

  • C1: Entrada válida — muestra nota requerida.
  • C2: Ya aprobaste — muestra mensaje positivo.
  • C3: Imposible — muestra advertencia.
  • C4: Validación — evita valores no numéricos.
  • C5: Limpieza — borra entradas y resultados.

8. Limitaciones y Suposiciones

  • Notas de 0 a 5.
  • No incluye pesos variables.
  • No admite comas como separador decimal.
  • No aplica redondeos institucionales.
